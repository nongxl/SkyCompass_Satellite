# 卫星 LoRa / UHF GFSK 数据接收、解析与长期记录系统实现方案 (v2.0)

> **版本说明**：本版本已根据用户评审标注全面调整：
> 1. 彻底去除手动强制开关键，全面聚焦于**“自动识别 + 自动过境开启”**；
> 2. 状态指示移出四角，改为在**过境卫星图标与定位点上动态渲染类似 WiFi 的扩散辐射波纹**；
> 3. 收包 Toast 弹窗调整至**屏幕上方中间弹出，持续 5 秒后自动淡出**；
> 4. RF Console 终端入口键由 `r` 调整为 **`Ctrl` 键**，且**严格保持主程序现有的统一配色规范**；
> 5. 为用户手动录入的自定义卫星**增加射频标识（下行频率、调制模式）的录入入口**，打通全自动过境监听链路。

## 细化设计方案与用户标注对齐

### 1. 自动过境与全自动开启机制（聚焦自动化）

* **全自动触发，零手动负担**：
  * 系统移除了额外的“强制开启”按键与复杂的模式切换逻辑。
  * 当用户在 Sat View 界面跟踪任意具备无线电参数的卫星（无论内置或自定义）时，后台线程以秒级周期评估轨道几何位置。
  * **AOS 预热窗口**：当预测仰角 $\text{El} > -3^\circ$（即预测出地平线前约 1~2 分钟），若检测到安装了 Cap LoRa-1262 模块，自动唤醒 SX1262 芯片，加载对应频率、SF、BW、CR 与同步字，进入待命接收状态。
  * **LOS 节能休眠**：卫星降入 $\text{El} < -3^\circ$ 达 2 分钟后，射频芯片自动进入 Deep Sleep，停止无谓功耗。

---

### 2. 自定义卫星的射频标识录入入口

针对用户在卫星百科中通过输入 NORAD ID 手动添加的卫星：
* **当前现状**：目前用户录入 NORAD ID 后，系统通过 WiFi 从 Celestrak 拉取 GP TLE 数据，但 TLE 仅包含轨道根数，不包含无线电下行频率与模式。
* **新增录入步骤/编辑入口**：
  1. **录入后向导提示**：当 TLE 成功下载后，系统弹出提示框询问是否配置无线电频段；
  2. **频段输入面板**：
     * **下行频率 (Downlink Freq)**：提供数字输入弹窗（如输入 `436.805`）；
     * **调制模式 (Radio Mode)**：提供快速滚轮选择（`LoRa (SF10/BW125/SW18)`、`LoRa (SF9/BW125/SW18)`、`LoRa (SF7/BW125/SW18)`、`4800 GFSK`、`9600 GFSK`、或纯文本自定义）；
  3. **存盘与绑定**：录入的射频标识直接通过 `Preferences` 持久化存储在 NVS 中。一旦录入完毕，该自定义卫星与内置卫星享有完全相同的自动过境监听待遇！

### 3. UI 视觉表现与交互规范（遵循主程序风格）

#### A. 屏幕过境卫星动态信号辐射波纹
* **避免四角拥挤**：Cardputer 屏幕四角已分别安排了 UTC 时钟、电量/定位状态、坐标多普勒、视角指南针。
* **位置与形式**：
  * 直接锚定在**当前过境卫星的图标与星盘投影定位点旁**；
  * 当射频处于监听状态时，从定位点向外侧以 1 Hz 频率动态扩散 2~3 道类似 **WiFi 广播的弧形波纹（Radiating Waves）**；
  * **颜色指示**：
    * 待命/监听中：显示主程序经典的柔和淡黄色或青色微光波纹；
    * 捕获到有效数据包瞬间：波纹高亮为鲜明绿色，并闪烁一次。

#### B. 屏幕正上方居中收包 Toast
* **位置**：屏幕顶部水平居中（Top-Center: `X = (240 - W)/2, Y = 6`），避开左右两侧的电量与时钟。
* **规格**：深蓝黑底色、青色/绿色高亮边框，高度约 16 像素。
* **显示内容**：`[RX] #01 RSSI:-106 SNR:+7.2dB`。
* **停留时间**：准确设定为 **5 秒后自动淡出消失**。

#### C. RF Console 专属监视终端
* **按键触发**：在 Sat View 下按键盘左下角的 **`Ctrl` 键**（避免与任何已有业务键冲突），在“Sat View 罗盘视图”与“RF Console 监视终端”之间无缝切换。
* **色彩与视觉规范**：
  * **完全沿用主程序风格规范**：黑色背景（`TFT_BLACK`）、标题及外框为冷青色（`TFT_CYAN`）、标签与数值为黄色/白绿色（`TFT_YELLOW` / `TFT_GREEN`）、副信息为浅灰（`TFT_LIGHTGRAY`）；
  * 杜绝任何突兀或与整体不协调的额外配色。
* **面板布局**：
  * **顶部信息**：卫星名称、当前多普勒补偿频率、实时 RSSI / SNR 水平条；
  * **中间 Hex 原始报文区**：显示最近接收的有效帧十六进制与 ASCII 转储；
  * **底部解析项目**：清晰排布已解出的物理量（电池电压、板卡温度、传感器读数等）；
  * **返回提示**：底部居中浅灰色提示语：“按 Ctrl 键返回罗盘跟踪”。

---

### 4. 数据持久化规范（MicroSD / Flash）

* **存储设备自动优选**：
  * 优先使用 MicroSD 卡插槽（挂载至 `/sd/lora_logs/`）；
  * 未插入 SD 卡时，自动回退到内部 Flash（LittleFS `/littlefs/lora_logs/`，预留 200KB 环形缓存）。
* **格式定义**：
  * **`.log`**：记录过境场次原始 Hex 数据流、UTC 时间戳、瞬时 RSSI、SNR 及频偏；
  * **`.jsonl`**：记录结构化遥测指标，方便通过读卡器导出后供电脑分析。

## 阶段化实施计划（Roadmap）

* [x] **Phase 1：硬件层驱动与自定义卫星录入扩展**
  * 引入 RadioLib 库，完成 Cap LoRa-1262 SPI 通信初始化与开机自检；
  * 在卫星百科中确立 `P` 键专属射频配置入口，支持 LoRa SF9/SF10 与 GFSK 预设及 NVS 持久化。
* [x] **Phase 2：轨道联动自动监听与屏幕动态辐射波纹**
  * 编写 `RadioManager`，实现根据卫星过境仰角（El > -3°）的自动唤醒与自动休眠；
  * 在 2D/3D 天空罗盘中为过境卫星图标增加动态扩散的 WiFi 弧形波纹；
  * 在屏幕正上方实现居中弹出、5 秒自动淡出的收包 Toast。
* [x] **Phase 3：统一风格 RF Console 终端与紧凑排版重构**
  * 实现按 `Ctrl` 键切换的全屏 RF Console，沿用统一经典调色板；
  * 新增 48px **信号瀑布能量图 (Mini Waterfall)** 与硬件 CRC 收包质量统计；
  * 支持按 `Tab` 键在“实时过境与瀑布图”与“报文列表与 HEX 详情”之间一键无缝切换；
  * 实现过境原始数据与遥测流水在 LittleFS / MicroSD 上的自动落盘。
* [x] **Phase 4：协议解析器与规则驱动通用数据字典**
  * 实现 AX.25 UI-frame 校验与解包；
  * 实现基于规则的通用星务数据字典（Telemetry Dictionary Engine），内建 NORBI、Vladivostok-1、FOSSASAT-2E、Edelveis 等立方星规则映射。
* [ ] **Phase 5 (未来展望)：全球地面站协同上传 (Global Station Feed)**
  * 支持在连接 WiFi 时，将抓取到的真实空间遥测 Hex 报文与信标异步上报至 TinyGS / SatNOGS DB 社区，加入全球分布式接收网络。
