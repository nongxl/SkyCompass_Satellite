# 🛰️ 卫星与航天冷知识卡片生成器 Prompt 模板

> 本模板用于指导大语言模型（如 Claude、ChatGPT、Gemini、DeepSeek 等）为 **SkyCompass Satellite** 批量生成开机冷知识卡片。
> 生成的数据可直接无缝追加至项目代码中的 [`src/core/trivia_data.h`](../src/core/trivia_data.h)。

---

## 📋 功能背景与硬件显示规范

在 SkyCompass 开机启动时（解析上百颗卫星 TLE 轨道根数、初始化 IMU 姿态解算与 LoRa/GNSS 外设需耗时数秒），屏幕会以半透明科技拟态卡片的形式循环轮播航天冷知识。

- **目标设备**：M5Stack Cardputer (ESP32-S3)
- **屏幕规格**：240 × 135 像素 彩色 TFT LCD
- **卡片显示区域**：宽 228px，高 80px，正文实际显示区域约宽 216px
- **字数硬性限制**：
  - **中文（zh）**：**38 ~ 52 字**（字号 12px，刚好舒适分为 2~3 行，绝不截断）
  - **英文（en）**：**18 ~ 26 单词**（两到三行，排版清晰）
  - **日文（ja）**：**50 ~ 65 字符**（使用内置 `efontJA_12` 字体）
  - **西班牙语（es）**：**18 ~ 28 单词**
- **主题标签（Topic）**：简短有力的 2~4 个词，如 `SPACESUIT SATELLITE` / `太空宇航服卫星`

## 🎯 推荐选题的 5 大极客维度

为了确保条目足够硬核、丰富、有趣且远离教科书式的陈词滥调，建议从以下 5 个方向搜集素材：

1. **真实乌龙与奇闻轶事**（宇航员太空丢工具包、双子座吹口琴谎报UFO、宇航服塞收音机当卫星等）
2. **业余无线电与空间黑客精神**（车库自制 OSCAR-1、TinyGS 分布式地面站、手持对讲机通 ISS、Python 驱动的 PROVES 立方星）
3. **卫星与空间物理极客知识**（多普勒频移导致频率漂移 20kHz、反作用飞轮无工质转向、反射太阳光的铱星耀斑瞬间超金星）
4. **太空垃圾与轨道寿命**（地球同步轨道的太空墓地、1mm 油漆微粒击穿宇航服、空间站每天下坠100米需货运飞船推高）
5. **肉眼观星与人类航天浪漫**（航天员每天看16次日出日落、旅行者1号20瓦信号飞越22小时等）

## 🤖 提示词模板（可直接复制投喂给 LLM）

```text
你是一位资深航天工程师与天文学科普作家，正在为开源手持人造卫星罗盘硬件（M5Stack Cardputer，屏幕 240x135 像素）撰写开机展示的“多语言卫星冷知识卡片”。

【撰写任务】
请围绕以下【事实主题列表】，为我创作 [数量，如 5 条] 精品冷知识条目：
[在此处粘贴你收集到的事实关键词，例如：
1. 宇航员遗落的抹刀在太空以高速飞行
2. 业余无线电卫星 OSCAR-1
3. 太阳风暴与地磁暴让卫星轨道迅速坠落
... 也可以留空让模型自由从上述5大维度挑选最有趣的真实事实]

【严格规范】
1. 真实准确：必须基于人类真实的航天历史、真实在轨卫星或严谨天体物理常识，杜绝科幻或事实虚构。
2. 字数严格限制（保证小屏幕两到三行显示，绝不超出）：
   - topic（主题标签）：中文 4~8 字，英文 2~4 词大写
   - text_zh（中文正文）：38 ~ 52 字以内
   - text_en（英文正文）：18 ~ 26 词以内
   - text_ja（日文正文）：50 ~ 65 字符以内
   - text_es（西班牙语正文）：18 ~ 28 词以内
3. 语言语调：极客浪漫、惊奇有趣、自然通顺、富有好奇心，避免生硬词条释义。
4. 输出格式：直接输出符合 C++ 语法结构体的代码块，格式如下：

    // 序号. 主题名称
    {
        "中文主题标签", "ENGLISH TOPIC", "日本語トピック", "TEMA EN ESPAÑOL",
        "中文正文...",
        "English text...",
        "日本語テキスト...",
        "Texto en español..."
    },
```

## 🛠️ 如何将新条目合并入项目

1. 打开项目中的文件：[`src/core/trivia_data.h`](../src/core/trivia_data.h)。
2. 将 LLM 生成的代码块直接复制并追加到 `s_satelliteTriviaList[]` 数组末尾。
3. 执行编译：
   ```bash
   pio run -e m5stack-cardputer
   ```
4. 重新烧录后开机即可看到全新卡片。开机时支持按 **`Space`**、**`Enter`** 或 **`.`** / **`;`** 键随时切页浏览！
